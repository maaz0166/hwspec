# hwspec

A command-line tool that shows your PC's hardware specs (CPU, memory, GPU, disk, battery) in one command.

**Status: work in progress.** This `0.0.1` release only reserves the name. The real tool, a C++ core with a Python wrapper for Windows, is under development.

Planned usage:

```
hwspec --cpu
hwspec --battery -d
hwspec --all
```
